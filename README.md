# Lowbridge

A browser cultivation incremental about an ordinary life in a mill village, an incomplete jade slip, and two ways to reconstruct its missing method. The first playable ends at Foundation. It is played in text, with capped resources, short practice runways, discoveries and a bank of unused time.

## Run locally

Requires Bun 1.4.x (developed with 1.4.0). The player bundle has no runtime dependencies.

```sh
bun install --frozen-lockfile
bun run dev
```

Open [Lowbridge on localhost](http://127.0.0.1:4173). The server builds on startup; restart it after source changes. To use another port: `PORT=4174 bun run dev`.

```sh
bun run typecheck
bun test
bun run validate
bun run validate:design
bun run build
bun run smoke
```

Browser smoke uses Playwright's Chromium (`bunx playwright install chromium` if the matching browser is not already present). It runs in isolated browser contexts and never uses a player's saved profile. The smoke server binds an available local port and shuts down when done.

## Playing and saving

The workspace separates Tasks, Techniques, Home, Craft and Character. Tasks opens with a **Now** panel that says where the story stands and what moves it on, from the first sack to the ridge's crossing; the actions it names carry a **Next** mark, though never one that would close other doors. Below it sit village work, **Practice** (mirrored under each knowledge on Character), the breakthrough panel, places, purchases and standing. Tasks is a grid of action buttons grouped by kind. Techniques and Home read like Arcanum's spell list and furniture table: one row per method or furnishing, with its cost and headline effect in a column of their own. Techniques counts attuned places at the top and puts **Attune** beside each method. Home counts floor spans at the top, lists each place and what fills it, and starts each furnishing's row with the place it fills or the floor it takes. Hovering or focusing a button shows its cost after discounts, duration, gains, next repetition threshold and any missing requirement, and the ⓘ button pins those details on touch screens. Values that have grown say where from ("Coin: 5 (+2 from 40 uses)"), rates and speeds read as "+0.005 Qi/s" or "+25% Rest speed", and a cap nothing you know of can raise says so. Newly discovered actions carry a **New** badge until inspected; a tab or group shows how many of its actions are New or Next, and at phone width the tab badge becomes a dot. A button you cannot use yet states what it needs in place of its cost line: every resource it is short of, with what you hold against what it needs, then any other condition, including how to free or expand floor space when a home arrangement is blocked. Stop and Accelerate show why they are unavailable in plain text rather than on hover. A chore whose payout would spill over a full resource says how much it would waste. Owned purchases and completed one-off visits move to a closed **Done** group at the end of their tab. Resources stay in a compact ledger: selecting a resource row (click, Enter or Space) marks the actions that give it in jade and those that spend it in amber, with a count on each tab, until you select it again or press Escape; selecting a knowledge row opens Character. Vigor, qi and Life sit in the Body panel with their net rate and the time until full. The current activity stays visible when you change tabs, with its objective editor, its progress and time left in real seconds at the current completion rate, and the reason the previous activity stopped; a paid run you stopped offers **Resume** with the time it has left. The breakthrough panel lists its bill as rows of held against needed ("Coin 29 / 40", then "paid"), and an unmet sign shows how far along it is. The place panel, the Character introduction, the footer and the accent colour follow the stage you have reached: the village, the ferry road after Foundation, Old Ridge, the waystation. Reaching Foundation raises a banner listing what it changed, and **Review** opens Character at "Beyond Foundation"; reaching the waystation raises one naming your direction, your standing and the activity time it took. Neither pauses anything. Steps that cannot be undone ask first in a modal confirmation that keeps focus until it is answered: a commitment says what it closes and what it brings, and taking down a furnishing, importing or starting again are marked as dangerous.

On a phone the columns stack. Any banner (Foundation, the return summary, news) comes first, above the current activity and the Body panel it reports on, and the tabbed activity panel follows them, then the ledger, Character status and the journal. The skip link and the summary's **Continue** move focus to the activity panel.

Actions come in two tempos. **Instant** ones (chores, trades and techniques) pay on the click without touching the activity slot or disturbing what is running. **Sustained** ones hold the slot: practice and **Rest** run continuously, while site visits, fights, Settling and the directions run for a set time. Starting a sustained activity sends the one it displaces to the front of a short waiting list instead of discarding it, and the slot picks the list back up when it frees, whether or not you are there. The waiting list and the **Queue** buttons stay out of sight until there is a second sustained activity to queue; once something is queued, the list says how long it will run unattended before time gathers in the bank. A paid timed run keeps its progress when you stop it and does not charge you twice to resume. An activity that cannot pay the next second of what it drains is refused with the reason. Furnishings can be taken down to free floor space; the confirmation says the cost is not returned and names any attuned method the lost place would release.

Chores are instant and cost Vigor. Haul a sack or sort a bundle and the pay lands at once, rising at the repetition thresholds each chore names. Clicking them is the attentive way to play and pays best. Some income comes in on its own, at your desk or away: after five sacks Wen puts you on a wage of a coin every twenty seconds, which counts toward your wages earned and stops for good when you take up the ferry road; apprenticing to Shu brings a share of her racks, a bundle every fifty seconds; and the herb rack and herb plot add a little more. When nothing is running or waiting, **Rest** takes over and brings Vigor and Life back to full; spending Vigor on a chore while it runs does not end it. While *Settle the breath* is attuned, Rest teaches Composure as well.

Choose an objective for one activity. It stops at its objective, when what it fills is full, or when it can no longer pay its way; discoveries are logged and marked **New** but never stop it. Unused real time goes into the bank. **Accelerate**, beside the bank, is a toggle that names the current objective. While it is on, every real second also spends one banked second on that activity, so progress runs at twice the ordinary pace until the objective stops or the bank is empty. It switches itself off when the activity ends. Returning to the game runs the saved activity to its next stop, then the waiting list, then Rest, and banks only the time with nothing left to run. A visit after a minute or more away opens with a summary of what happened and what entered the bank, ending with what is still waiting and what to do next.

Using a method takes three steps. You **learn** it from a place or a practice, you **attune** it into one of the few places your mind holds ready, and then you can **use** it for qi. Attunement starts at a single place; the practice mat buys another and Foundation gives a third, which the ridge's methods fill. The channel and the hollow teach opposite readings of the slip's missing turn (carry it, or let it settle), and attuning one closes the other for good. The game says so in plain words before you commit. Foundation asks for the reconstructed method, three of four preparations including two methods held attuned, a bill in herbs and coin, and a full qi reservoir. Play that keeps the activity slot busy and stops once the Foundation panel is satisfied reaches it in about ten active minutes, and no outing or sitting before it runs longer than three. The ridge, from Foundation to the waystation, takes roughly another fifteen to twenty.

Every method you hold carries **route keys** that name what it is made of: the channel's reading or the hollow's, and the school it comes from (body, earth, sword or formation). A method counts toward its keys once you have used it. Each method's details list its keys by name, and Character shows a **Route keys** section with every key you hold and the method that carries it. The rest of the journey asks about them, so it never asks which particular chores you did. Visiting one place does not forbid the other, and a method both routes share keeps them from diverging completely.

After Foundation the ferry road leads up to Old Ridge. Its outskirts offer four teachings, the porter's notes on carrying, on the blade, on the ground and on layout, each bought from the porter's widow with herbs at Lore 3. Each opens a **sphere**: a family to practise, drills that want a frame on one span of your floor, a site and a chore of its own, and a **pair** of methods to attune that read the sphere two ways and close each other. *Sink the breath under the load* or *Rise under the load* (body), *Cut by intent* or *Let the blade wait* (sword), *Read the grain* or *Walk where it slid* (earth), *Fix a layout* or *Open a layout* (formation): holding one half closes the other for good, the confirmation says so, and the half you hold is what carries its numbers, Life and Guard or Speed and Dodge, Strike and Hit or Guard and Dodge. The game says so in plain words before you commit.

There is one **First Direction**, a three-minute breakthrough that any sphere carried to four takes, with its drills begun; it closes nothing and raises every sphere you carry at four. Its other signs are Lore 4, a furnished home (a cot, a herb plot or a strongbox), a method of that school held and used, and two hundred coin earned in wages; it needs three of the four, twenty herbs and sixty coin, and twelve of the sphere's material in hand. When it completes, your **title** is read from what you carried, Body Disciple, Sword Disciple, Earth Listener or Formation Student, and the title changes what earlier work pays. A 90-second crossing, with a held method of its school, then takes you to the waystation. Your leaf-eight reading follows you up: the channel's makes the crossing quicker and the earth notes cheaper, the hollow's makes the body notes cheaper and ridge outings drain Strain more slowly.

The waystation opens the **basin road**. Keeper Han's board carries four leads: route records toward the basin, a chime at dusk, a spur that ends at a slide, and the slip's other nine leaves. Outings here draw on **Focus** as well as Strain, a second gauge in the Body panel that Rest brings back in about eighty seconds. Each sphere carried to five opens a deeper teaching at Lore 5 (the conditioning sheets, Old Tam's second lesson, the ground-current accounts, the survey overlay, and Shu's three leaves, which open Refining and the pill sphere), and each teaching offers a deep pair to hold, a three-minute site that raises the sphere's cap, and a **commission** from Han once the sphere stands at six. Six of the slip's leaves are recovered on the road, each patching what chapter one pays. The **Second Direction** asks for two spheres deepened and three methods held, four of six signs (fifteen uses of the deep methods, the chime explained, a working study, the spur reopened, a commission done, four leaves), thirty herbs, a hundred and fifty coin and a full reservoir; it closes nothing. Its title is read from what you hold, the four hybrids first (Mountain Vessel, Blade Body, Earth Array Adept, Intent Warden), then Pill Refiner, then the pure titles by the sphere trained higher (Iron Marrow Adept, Spirit Blade, Deep Listener, Array Keeper). It grants a fifth attunement place and the **hobby** place: a marked practice (the slip's two, the sphere drills, the refining drills) runs there at half pace beside whatever holds the slot, keeps running while you are away, and has its own Stop under the current activity. The terrace above the slide then reaches Reedmarket, on the Cloudwell basin's edge.

Fights appear under **Fights** once Circulation opens, along with **Life** in the Body panel. Each side's readiness fills by its **Speed** every second and it swings when the bar is full, every 5 seconds at Speed 1. A swing lands with your **Hit** chance less the foe's **Dodge**, and deals your **Strike** minus their **Guard**; theirs works the same way against you. Circulation and held methods raise these. The fight card and its tooltip lead with a verdict worked out exactly from those rules: **Certain win**, **Likely win**, **Close** or **Likely loss** with your chance ("Likely win · about 84%"), or "Cannot win: Strike 4 does not pass Guard 5". Below it one line names the cheapest change that would improve it (resting to full Life, holding another method and what holding it closes, or a higher Strike and what raises it), then both sides' numbers, the foe's technique if it has one, and the mean time each outcome comes. Every swing is rolled, so a likely win can still go wrong. Once begun, the fight opens its own **Fight** tab: both Life bars, both readiness bars, and the blow-by-blow, also kept in the journal. The finished fight stays there until you start something else yourself. It ends when a side falls, or is lost if the minute runs out, and cannot be stopped halfway. Losing empties Life, which returns slowly on its own and in about five minutes of Rest, and costs what you brought, never a discovery; a fight refused for want of Life says how soon you will be ready. The sparring bout with the ferry hand stakes nothing; the man on the porters' path stakes your herbs.

The man on the porters' path is optional. He cannot be beaten at Foundation; the Body and Sword lines can beat him after their training, and the Earth and Formation teachings each open a 90-second site that traces his cache without meeting him. Either way opens the cache. The two men at the spur, on the basin road, are optional too: every third swing is their rush at Strike 16, which only Guard turns, so a held method that raises Guard (the body's, the earth's rooting, the sword's waiting blade) is what changes the odds, and the loss text names them.

The **Craft** tab opens after Foundation once a workbench (one span of floor, so it is a reason to buy the cottage) is installed. Its recipes hold the activity slot while they run and make either **kit**, a piece carried at 1/1 that raises a stat while held (a honed edge for Strike, a warding strip for Dodge), or **preparations**, doses kept up to three that are taken on the instant (a poultice for Vigor, a marrow tonic for Life and Strain). Both are listed under **Preparations** in the ledger on the left. Once Refining opens, the clay vessel steeps **draughts** that last: a settling draught slows the Strain and Focus drains by a quarter for ten minutes of activity, Rest included, a marrow draught speeds the carrying drills and the scree climb for five; drinking another starts the clock again, and the ledger lists what is in effect and how long is left. Han's specimen case is fitted at the bench and delivered for coin and a level more of Lore.

No age, lifespan or retry ends a journey. A failed attempt costs the time and the preparation it used, keeps everything you discovered, and hands the choice back to you.

Progress saves in this browser's IndexedDB. A second tab cannot run the same journey at the same time. **Export** in the save controls creates a portable JSON copy; **Import** asks for confirmation, then resumes that snapshot without adding the time since its export. A save holds only what you actually did (values, experience, repetitions, what you have attuned, the hobby running, the draughts in effect and what you have seen). Every derived number is rebuilt from the content when it loads, so a rebalance reaches an existing journey without a migration. Saves are version 7, and older saves cannot be loaded: the game refuses them by version and leaves the running journey alone. A new journey replaces the current one after confirmation.

Time away is settled from the saved wall-clock time. An open visit uses a monotonic clock, so system clock corrections neither freeze progress nor count time twice. Browser and operating-system suspend behavior can affect an open visit; closing the tab gives the clearest away-time boundary.

ADR 0024's seam is in force: `bun run validate` fails a gate in one chapter's file that names a record from another, and each chapter reads the earlier ones only through route keys and shared stores. This slice has one optional fight before Foundation, one on the ridge and one on the spur; the spur pair is the first foe with a technique, and held methods are the only per-fight preparation. Two dungeons, the surveyors' adit and the Reedmarket cistern, run rooms in order in the one slot (a fight room per dungeon, doors between rooms, a lost fight resetting only its room; ADR 0032); there are no sect or waystation modules. Reedmarket's two still-missing leaves show where the next slice begins. The Python design validators remain alongside the TypeScript validator, which runs real content and engine behavior.
