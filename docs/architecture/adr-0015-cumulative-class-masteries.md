ADR 0015: Cumulative class masteries and initial overlap

Status: Accepted counting rule and initial assignments; later classes, thresholds, and exact benefits remain open. Date: 16 October 2026. Basis: explicit answer Q66.

Each acquired class adds +1 to each mastery listed on that class. Contributions are retained with the class history. A total records the number of contributing acquired classes; it is a qualification for later opportunities, not spendable currency or a separately trainable skill level.

The four starting directions have these assignments:

| Starting direction | Contributions |
|---|---|
| Body | Body +1 |
| Sword | Sword +1, Spirit +1 |
| Earth | Earth +1 |
| Formation | Formation +1, Spirit +1 |

Spirit means projecting awareness and will beyond the body. It is distinct from the basic qi perception that all cultivators may develop. Sword and Formation share that expertise. Body and Earth must have distinctive class benefits that make their narrower mastery contributions worthwhile; tag count alone does not determine a class's value. Exact benefits and balance remain in design.

Techniques develop separately through teaching and practice, within the accepted limits of current understanding. Repeating a technique does not add class mastery contributions. A mastery qualification does not waive the teaching, preparation, or other requirements of an opportunity.

These contributions belong to character state and follow the existing exact-state checkpoint restore rules. Retained class history is not an exception granting post-checkpoint mastery after a retry. This decision does not settle whether earlier class choices can be revised.

The decision does not approve the later class roster, its assignments or mastery thresholds, or the exact benefits, costs, and durations in the [class-map sketch](../../design/CULTIVATION-CLASS-MAP.md). The first dedicated alchemy class is already scheduled for breakthrough 3, but its particular assignments and entry requirements remain proposed.

Subsequent Q67 accepts the five breakthrough-3 candidates, their mastery gates and contributions, and Pill Refiner's accessibility from every starting class through teaching and practical preparation. [ADR 0016](adr-0016-third-breakthrough-classes.md) records that addition; the exact preparation and benefit packages remain open.
